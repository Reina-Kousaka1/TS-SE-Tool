# macOS packaging

The workflows are configured to create an unsigned `.app` bundle and compressed DMG from each macOS self-contained publish directory. The bundle contains the apphost and publish output in `Contents/MacOS`, an `Info.plist`, and the repository's Apache-2.0 license in `Contents/Resources`. The bundle identifier `com.github.reina-kousaka1.ts-se-tool` is derived from the repository identity and is provisional until signing/distribution setup is approved.

The latest full matrix [45805099779](https://github.com/Reina-Kousaka1/TS-SE-Tool/actions/runs/45805099779) on `84552a7` passed all seven jobs. macOS Intel passed 102/102 tests and the `.app`/DMG build, plist validation, read-only mount, bundled-app launch, and detach check. The explicit Apple Silicon run [45805099903](https://github.com/Reina-Kousaka1/TS-SE-Tool/actions/runs/45805099903) on the same source passed 102/102 tests, self-contained publish, bundle/DMG build and mount verification, and native startup/shutdown. The earlier Apple Silicon run [45795444731](https://github.com/Reina-Kousaka1/TS-SE-Tool/actions/runs/45795444731) ended with a cancelled job and no assigned runner, steps, or accessible log; its cause remains unknown, but the current source has since passed the explicit `macos-15` route. No package is signed, notarized, uploaded, or released. Gatekeeper, hardened runtime, signing, notarization, icon/accessibility review, and DMG installation on a clean user system remain unverified.

Avalonia's [macOS deployment guide](https://docs.avaloniaui.net/docs/deployment/macos) documents the `.app` layout, `Info.plist`, and the additional signing/notarization work needed for distribution.
