# macOS packaging

The workflows are configured to create an unsigned `.app` bundle and compressed DMG from each macOS self-contained publish directory. The bundle contains the apphost and publish output in `Contents/MacOS`, an `Info.plist`, and the repository's Apache-2.0 license in `Contents/Resources`. The bundle identifier `com.github.reina-kousaka1.ts-se-tool` is derived from the repository identity and is provisional until signing/distribution setup is approved.

Latest full matrix [45809139497](https://github.com/Reina-Kousaka1/TS-SE-Tool/actions/runs/45809139497) passed all tests and six of seven jobs. macOS Intel passed 104/104 tests, self-contained publish, DMG creation, read-only mount, plist validation, and bundled-app startup/shutdown; the verifier then failed at detach, so the run did not pass packaging. The verifier now retries detach and preserves the mounted volume if it cannot safely unmount; the change is awaiting CI. The last explicit Apple Silicon run [45805099903](https://github.com/Reina-Kousaka1/TS-SE-Tool/actions/runs/45805099903) passed on earlier source; a fresh ARM64 run has been requested for both the bounded transaction hash and detach fix. The earlier Apple Silicon cancellation [45795444731](https://github.com/Reina-Kousaka1/TS-SE-Tool/actions/runs/45795444731) left no assigned runner, steps, or accessible log; its cause remains unknown. No package is signed, notarized, uploaded, or released. Gatekeeper, hardened runtime, signing, notarization, icon/accessibility review, and DMG installation on a clean user system remain unverified.

Avalonia's [macOS deployment guide](https://docs.avaloniaui.net/docs/deployment/macos) documents the `.app` layout, `Info.plist`, and the additional signing/notarization work needed for distribution.
