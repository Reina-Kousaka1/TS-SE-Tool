# macOS packaging

The workflows are configured to create an unsigned `.app` bundle and compressed DMG from each macOS self-contained publish directory. The bundle contains the apphost and publish output in `Contents/MacOS`, an `Info.plist`, and the repository's Apache-2.0 license in `Contents/Resources`. The bundle identifier `com.github.reina-kousaka1.ts-se-tool` is derived from the repository identity and is provisional until signing/distribution setup is approved.

Full matrix [45791992179](https://github.com/Reina-Kousaka1/TS-SE-Tool/actions/runs/45791992179) passed the Intel `.app`/DMG build, plist validation, read-only mount, bundled-app launch, and detach check, plus 96/96 tests on macOS Intel. The latest successful Apple Silicon validation [45787021904](https://github.com/Reina-Kousaka1/TS-SE-Tool/actions/runs/45787021904) passed 86/86 tests on an older commit. A new targeted run is requested for current source. No package is signed, notarized, uploaded, or released.
