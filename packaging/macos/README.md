# macOS packaging

The workflows are configured to create an unsigned `.app` bundle and compressed DMG from each macOS self-contained publish directory. The bundle contains the apphost and publish output in `Contents/MacOS`, an `Info.plist`, and the repository's Apache-2.0 license in `Contents/Resources`. The bundle identifier `com.github.reina-kousaka1.ts-se-tool` is derived from the repository identity and is provisional until signing/distribution setup is approved.

Full matrix [45811585441](https://github.com/Reina-Kousaka1/TS-SE-Tool/actions/runs/45811585441) on `222b82a` passed all seven jobs. macOS Intel passed its .NET 10 tests, self-contained publish, `.app` and DMG creation, plist validation, read-only mount, confirmed detach, and bundled-app startup/shutdown. Apple Silicon run [45811585565](https://github.com/Reina-Kousaka1/TS-SE-Tool/actions/runs/45811585565) also passed the full test suite, publish, `.app`/DMG verification, and native startup/shutdown. The earlier Apple Silicon cancellation [45795444731](https://github.com/Reina-Kousaka1/TS-SE-Tool/actions/runs/45795444731) left no runner, steps, or accessible log; its cause remains unknown. No package is signed, notarized, uploaded, or released. Gatekeeper, hardened runtime, signing, notarization, icon/accessibility review, and DMG installation on a clean user system remain unverified.

Avalonia's [macOS deployment guide](https://docs.avaloniaui.net/docs/deployment/macos) documents the `.app` layout, `Info.plist`, and the additional signing/notarization work needed for distribution.
